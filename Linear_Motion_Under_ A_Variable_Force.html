The 6 Classic CAIE 9231 Exam Traps

How Cambridge examiners twist questions and where students drop marks

Trap 1: Integrating a(x) with respect to time

When acceleration is given as a function of position $a(x)$, never write $\int a(x) dt$. The variables don't match! You must immediately use $a = v\frac{dv}{dx}$ so you can separate: $\int v\,dv = \int a(x)\,dx$.

Trap 2: Assuming the constant of integration is 0

When $t=0$, functions like $e^{0} = 1$, $\cos(0) = 1$, or $\ln(0+1) = 0$ appear. Many students instinctively set $c = 0$ or $c = v_0$ without evaluating the algebraic substitution. Always write out $v(0) = f(0) + c$ explicitly!

Trap 3: Distance travelled vs Displacement when v changes sign

If velocity changes sign (e.g. projectile or reversing particle), displacement $\Delta x = x(t_2) - x(t_1)$ is NOT equal to total distance. You MUST find where $v = 0$, split into intervals, and sum absolute values $\int |v| dt$.

Trap 4: Integrating unnecessarily to find Maximum Velocity

Maximum velocity occurs when $\frac{dv}{dt} = 0$, which means Acceleration $a = 0$ (Net Force $= 0$). You can usually find the position or time of $v_{\text{max}}$ in one step by setting the acceleration formula to zero!

Trap 5: The "Time to stop" vs "Distance to stop" choice for $F(v)$

If an exam asks: "Find the time taken to come to rest", use $\frac{dv}{dt} = f(v) \implies dt = \frac{1}{f(v)} dv$. If it asks: "Find the distance travelled before coming to rest", use $v\frac{dv}{dx} = f(v) \implies dx = \frac{v}{f(v)} dv$. Choosing the wrong form wastes 10 minutes trying to convert.

Trap 6: Coulomb Friction acting in reverse

Surface friction $\mu mg$ always opposes existing motion. Once $v = 0$, friction drops to 0 unless a remaining external force exceeds $\mu mg$. In numeric simulations, if you let friction keep acting after $v=0$, it unphysically pulls the particle backwards!
